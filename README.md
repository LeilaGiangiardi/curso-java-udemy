# ☕ Curso Java Completo - Nelio Alves (Udemy)

Este repositório documenta minha trajetória no curso **Java Completo: Programação Orientada a Objetos + Projetos**, focado em construir uma base sólida para desenvolvimento de software.

---

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** Java 25 (LTS)
* **IDE:** Visual Studio Code
* **Controle de Versão:** Git/GitHub

---

## 📂 Organização e Conteúdo do Curso

O projeto é dividido em pastas que representam as seções do curso. Cada pasta contém seu próprio material de estudo e resoluções de exercícios:

### 🟢 Fundamentos e Lógica
* **`sc04_estrutura_sequencial`**: Operadores aritméticos, entrada e saída de dados.
* **`sc05_estrutura_condicional`**: Lógica de decisão e operadores lógicos.
* **`sc06_estruturas_repetitivas`**: Estruturas de laço (while, for).
* **`sc07_outros_topicos_basicos`**: Funções e sintaxe adicional.

### 🔵 Programação Orientada a Objetos (POO)
* **`sc08_introducao_poo`**: Classes, atributos, métodos e estáticos.
* **`sc09_construtores_encapsulamento`**: Sobrecarga e a palavra `this`.
* **`sc10_comportamento_memoria_arrays_listas`**: Alocação, vetores e listas.
* **`sc11_topicos_especiais_data_hora`**: Manipulação de datas e horários no Java.
* **`sc12_enumeracoes_composicao`**: Modelagem de entidades complexas.
* **`sc13_heranca_polimorfismo`**: Reuso e extensibilidade de código.

### 🟡 Tópicos Avançados
* **`sc14_tratamento_excecoes`**: Segurança e tratamento de erros (Try-Catch).
* **`sc15_trabalhando_com_arquivos`**: Leitura e escrita de arquivos (File, Scanner).
* **`sc16_interfaces`**: Desacoplamento e inversão de controle.
* **`sc17_generics_set_map`**: Coleções tipadas e estruturas de dados.
* **`sc18_programacao_funcional_lambda`**: Expressões lambda e Streams API.

### 🟣 Projetos e Bônus
* **`sc19_nivelamento_git_github`**: Versionamento avançado de código.
* **`sc20_acesso_banco_dados_jdbc`**: Conectividade com SQL.
* **`sc21_mapeamento_objeto_relacional_jpa_hibernate`**: Persistência de dados.
* **`sc22_projeto_web_services_spring_boot`**: Criação de APIs REST.
* **`sc23_projeto_sistema_xadrez`**: Exercício completo de lógica e POO.
* **`sc24_projeto_spring_boot_mongodb`**: NoSQL e Web Services.
* **`sc25_interface_grafica_javafx`**: Desktop (Legado Java 11).
