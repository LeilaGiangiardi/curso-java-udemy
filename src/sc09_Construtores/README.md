# Seção 9: Construtores, palavra this, sobrecarga, encapsulamento

Nesta seção do curso de Java (Udemy), foram explorados conceitos fundamentais para a criação de classes robustas e seguras, focando na integridade dos dados e na flexibilidade da instanciação de objetos.

## 📌 Tópicos Abordados

*   **Construtores:** Implementação de operações especiais que executam no momento da instanciação do objeto, permitindo a passagem de dados obrigatórios.
*   **Palavra `this`:** Utilizada para referenciar o próprio objeto, diferenciando atributos de variáveis locais e permitindo chamadas entre construtores.
*   **Sobrecarga:** Criação de múltiplos construtores na mesma classe para oferecer diferentes formas de iniciar um objeto (ex: com ou sem depósito inicial).
*   **Encapsulamento:** Proteção de atributos com o modificador `private`, expondo o acesso de forma controlada através de métodos `get` e `set`.
*   **Modificadores de Acesso:** Compreensão da visibilidade de membros (`private`, `public`, `protected` e `default`).

## 🛠️ Exercícios Desenvolvidos

1.  **ex01_estoque:** Evolução do sistema de estoque utilizando construtores para evitar produtos com dados nulos e sobrecarga para permitir entradas parciais.
2.  **ex02_banco (Exercício de Fixação):** Sistema bancário completo que simula abertura de conta, depósitos e saques com taxas, aplicando todos os conceitos de encapsulamento e proteção de saldo.
