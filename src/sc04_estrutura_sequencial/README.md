# ☕ Seção 4: Estrutura Sequencial

Este módulo foca nos fundamentos da lógica de programação sequencial em Java, abrangendo desde a manipulação de dados básica até o processamento de informações com cálculos matemáticos e interação com o usuário.

---

## 🧠 Conceitos Aprendidos

* **Saída de Dados:** Exibição de informações no console e formatação de números decimais com `printf` e `Locale`.
* **Casting:** Conversão explícita entre tipos de dados (ex: `int` para `double`) para garantir a precisão dos cálculos e evitar perda de dados.
* **Entrada de Dados:** Utilização da classe `Scanner` para capturar e processar dados digitados pelo usuário via teclado.
* **Funções Matemáticas:** Aplicação da biblioteca `Math` para operações essenciais como raiz quadrada (`sqrt`), potência (`pow`) e valor absoluto.

---

## 📂 Organização dos Arquivos

### Aulas Teóricas e Exemplos
* **`A01_saida.java`**: Prática de saída de dados, concatenação e formatação.
* **`A02_Casting.java`**: Exemplos de processamento de dados e o uso de casting.
* **`A03_scanner.java`**: Implementação de entrada de dados simples e composta.
* **`A04_funcao_matematicas.java`**: Testes práticos com as funções da biblioteca padrão do Java.
